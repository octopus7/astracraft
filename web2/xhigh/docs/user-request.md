# 요청 원문

> D:\github\astracraft 저장소에서 첨부 참고 이미지와 동일한 방향의 플레이 가능한 쿼터뷰 3D SF 수리 지구 게임을 제작해 주세요. 작업 위치는 반드시 web2/xhigh/입니다. 모델링도 직접 제작하고 UV는 정리된 0–1 범위의 비중첩 UV로 구성하세요. 다른 엔진으로 내보낼 수 있도록 범용 glTF 2.0(.gltf + .bin + PNG)과 표준 PBR 머터리얼을 사용하세요. UV에 맞는 텍스처는 ImageGen으로 생성하거나 조합하고, 프롬프트 원문 및 실제 제작 프롬프트를 web2/xhigh/docs/ 아래 문서로 정리하세요. web2/index.html 대문에서 /xhigh/로 이동할 수 있는 카드/링크도 추가하세요. 현재 다른 작업들이 web2/medium 및 web2/high를 동시에 만들고 있으니 그 하위 폴더들은 수정하지 말고, 공용 web2/index.html을 수정할 때 기존 변경과 medium/high 링크를 반드시 보존하세요. 구현, 모델 검증, 빌드/테스트를 완료한 뒤 이 xhigh 작업의 파일만 선별하여 커밋하세요.

## 참고 화면에서 추출한 방향

- 높은 산업 벽체에 둘러싸인 중앙 수리 광장
- 비가 내리거나 막 그친 뒤의 젖은 석재 바닥과 낮은 안개
- 청록 신호광과 호박색 정비등이 섞인 어두운 SF 팔레트
- 쿼터뷰 카메라, 얇은 선과 모노스페이스 활자를 사용한 HUD
- 작은 정비 로봇을 움직여 여러 신호 노드를 복구하는 플레이 흐름

참고 이미지는 장면과 UI를 그대로 복제하기 위한 원본이 아니라, 카메라·밀도·재질감·조명 방향을 정하는 시각 참고로만 사용했습니다.
