# The Rain Court — medium

비가 내리는 SF 수리 지구를 탐사하며 세 개의 중계기를 복구하는 쿼터뷰 3D 웹게임이다.

## 실행

저장소 루트에서 `cd web2`, `npm install`, `npm run dev`를 실행하고 `/medium/`을 연다.

## 조작

- 드래그: 카메라 회전
- Shift + 드래그: 카메라 이동
- 휠: 확대/축소
- WASD 또는 지면 클릭: 정비 드론 이동
- 빛나는 중계기에 접근: 자동 복구

범용 모델 내보내기와 UV 규약은 [docs/modeling.md](docs/modeling.md), 생성 프롬프트는 [docs/asset-prompts.md](docs/asset-prompts.md)에 정리되어 있다.
