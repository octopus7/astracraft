# 사용자 지시 원문

## 최초 요청

> web2 라고 경로 만들고 이런 비주얼의 게임 만들어볼수있어? 어떤 화면인지 이해한대로 말해봐

참고 이미지: 비가 그친 산업 도시의 중앙 광장을 내려다보는 쿼터뷰 3D 게임 화면. 좌측 지역 정보, 우측 미니맵, 하단 자유 카메라 조작 패널이 표시되어 있다.

## 제작 지시

> 모델링까지 네가 직접하라는거야 UV 는 제대로 정리된 형태라야하고 텍스쳐는 imagegen을 이용해 uv에 맞게 생성하거나 조합해
>
> 다른 엔진으로 모델링을 보낼수있도록 파일 포맷이나 머터리얼은 범용적인걸로 해줘
>
> 작업 시작해
>
> 내가 지시한 프롬프트도 하위경로에 따로 문서로 정리해
>
> 작업 끝나면 커밋

## 경로 수정 지시

> web2 하위에 medium 이라는 경로를 만들고 그안에 넣어줘 web2 는 해당경로상 페이지로 연결하는 대문이고 이후 다른 하위경로도 만들거야
