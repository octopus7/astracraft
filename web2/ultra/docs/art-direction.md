# VOIDWRENCH 아트 디렉션

## 장면 언어

`R-07 Drydock`은 거대한 함선의 외피가 아니라, 그 함선을 계속 살려 두는 사람과 기계가 머무는 정비 구역입니다. 카메라는 35° 전후의 쿼터뷰를 유지하고, 플레이 동선은 어두운 흑연색 바닥 위의 황색 안전선과 청록색 진단광으로 읽힙니다.

환경은 세 층으로 구성됩니다.

1. **바닥층** — 데크 플레이트, 배수구, 케이블, 위험 구역
2. **작업층** — 전력 릴레이, 냉각 펌프, 안테나, 크레인 콘솔, 수리 베이
3. **실루엣층** — 격납고 벽, 서비스 타워, 안테나와 멀리 보이는 작업등

## 색과 상태

- 청록: 탐색, 안전한 에너지, 스캔 결과
- 황색/호박색: 상호작용 가능, 작업 진행, 보급품
- 주황: 오래된 수리 패치와 현장 장비
- 적색: 방전, 과열, 내구도 위험
- 아이보리: 플레이어 서비스 로버의 주 실루엣

수리가 끝난 설비는 적색 불꽃과 불안정한 진동이 멈추고 청록색 상태 링으로 전환됩니다. UI와 월드의 상태색을 같게 유지해 텍스트를 읽지 않아도 상황을 파악할 수 있도록 했습니다.

## 모델 제약

- Y-up, 미터 단위
- glTF 2.0 JSON + 외부 BIN + 외부 PNG
- Metallic-Roughness 표준 PBR 워크플로
- 0–1 UV 및 메시 내부 UV 삼각형 비중첩
- 특정 웹 런타임에 종속된 셰이더/압축 확장 없음
