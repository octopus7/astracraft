# 제작 요청 원문

> D:\github\astracraft 저장소에서 첨부 참고 이미지와 동일한 방향의 플레이 가능한 쿼터뷰 3D SF 수리 지구 게임을 제작해 주세요. 작업 위치는 반드시 web2/ultra/입니다. 모델링도 직접 제작하고 UV는 정리된 0–1 범위의 비중첩 UV로 구성하세요. 다른 엔진으로 내보낼 수 있도록 범용 glTF 2.0(.gltf + .bin + PNG)과 표준 PBR 머터리얼을 사용하세요. UV에 맞는 텍스처는 ImageGen으로 생성하거나 조합하고, 프롬프트 원문 및 실제 제작 프롬프트를 web2/ultra/docs/ 아래 문서로 정리하세요. web2/index.html 대문에서 /ultra/로 이동할 수 있는 카드/링크도 추가하세요. 현재 다른 작업들이 web2/medium, web2/high, web2/xhigh를 동시에 만들고 있으니 그 하위 폴더들은 수정하지 말고, 공용 web2/index.html을 수정할 때 기존 변경과 medium/high/xhigh 링크를 반드시 보존하세요. 구현, 모델 검증, 빌드/테스트를 완료한 뒤 이 ultra 작업의 파일만 선별하여 커밋하세요.

## 이 작업에서 확인한 입력 상태

분기된 Ultra 작업 대화에는 참고 이미지 파일이 전달되지 않았습니다. 따라서 시각적 방향은 요청문에 명시된 핵심어인 `쿼터뷰`, `3D`, `SF`, `수리 지구`를 기준으로 해석했습니다. 산업용 궤도 드라이독, 청록 진단광, 황색 안전 표시, 마모된 금속 패널을 중심으로 독자적인 비주얼을 구성했습니다.
