# 사용자 요청과 제작 범위

참조 이미지: `../../prompts/reference.png` (3679 × 2118 PNG, 직접 열어 구도 분석).

전달된 사용자 승인 요청:

> 첨부 참조 이미지를 직접 열어 분석하고 AFTERLIGHT / The Rain Court 장면을 제작한다. Blender에서 직접 실제 메시 모델링, 정리된 UV(체커/아일랜드 여백/의도한 반복 외 비중첩), ImageGen으로 UV에 맞는 텍스처 생성 또는 조합, 표준 PBR 재질, 다른 엔진으로 이동 가능한 GLB/glTF와 FBX 및 원본 .blend, 제작 스크립트와 UV 레이아웃을 제공한다. 폐허 산업도시 안뜰, 벽돌 담장, 상점/건물, 배관, 상자, 로봇, 비 갠 뒤 젖은 바닥, 따뜻한 조명과 청록색 포인트를 재현한다. 웹 페이지는 실제 3D 모델 회전/이동/확대와 결과 파일 다운로드를 제공하고 화면의 세련된 게임 HUD 분위기를 반영한다. 사용자 프롬프트도 하위 docs 경로에 문서화한다. 지정 경로 안에서 독립 제작하고 시각 검증, export 검증, 웹 로딩 검증 후 해당 경로만 git 커밋한다. 다른 작업의 파일을 변경하거나 커밋하지 않는다. 독립 headless Blender 프로세스만 사용한다. ImageGen은 내장 image_gen 도구를 사용한다. 외부 CDN 없이 웹이 실행되도록 의존성을 지정 경로에 제공하거나 빌드한다.

지정 경로: `web3/xhigh/`. 추론 강도: xhigh. 기존 `web2/` 파일은 사용자 작업이므로 변경하지 않는다. `web3` 대문은 부모 작업이 담당한다.

추가 배포 설정:

- Pages Framework: None
- Build command: `exit 0`
- Build output directory: `web3`
- `xhigh/index.html` 자체가 배포 가능한 정적 진입점이다. 홈 링크는 `../`이다.
- 모든 브라우저 의존성은 로컬 제공한다. `/web3/` 접두사를 사용하지 않는다.
- 각 배포 파일은 25 MiB 미만이어야 한다.
- 대문용 `preview.png`, 렌더 경로, 최종 커밋 해시를 제공한다.

구도 해석: 전경이 열린 높은 벽돌 안뜰, 뒤편 수리점과 청록빛 방화문, 세 종류의 서비스 로봇, 실제 개별 포장석과 얕은 빗물, 노후 배관과 환기장치, 소량의 담쟁이와 잔해. 완성 장면은 이 구도를 바탕으로 만든 독자적인 메시 디오라마이며, 참조 이미지를 평면 배경으로 투사한 장면이 아니다.
