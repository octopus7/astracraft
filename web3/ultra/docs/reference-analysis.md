# AFTERLIGHT / The Rain Court — 참조 분석

원본: `../../prompts/reference.png`. 제공된 이미지를 직접 열어 분석했다. 이 문서는 참조 화면에서 관찰한 요소와 3D 재구성의 설계 기준을 구분한다.

## 참조에서 관찰한 구성

- 카메라는 안뜰을 비스듬히 내려다본다. 낮게 무너진 전경 담장과 높은 좌우·후면 건물이 사각형의 빈 공간을 감싸며, 젖은 바닥이 화면 중앙의 넓은 여백을 만든다.
- 담장은 회갈색 벽돌과 돌의 층으로 이루어져 있다. 고르지 않은 상단, 기둥, 파손된 틈, 벽면의 수직 배관, 드리운 식물이 반복되어 산업도시의 오래된 질서를 드러낸다.
- 후면 오른쪽의 작은 상점은 붉은 갈색 경사 차양, 어두운 청록색 문과 패널, 입구 양옆의 호박색 램프가 특징이다. 그 왼쪽의 큰 문에는 가늘고 밝은 청록색 수직 조명이 있다.
- 바닥의 장방형 포장판은 크기와 방향이 조금씩 다르며, 균열·배수구·잔해와 얕은 물이 섞여 있다. 따뜻한 입구 조명과 청록색 불빛이 바닥에 길게 반사된다.
- 목재 상자는 좌측과 후면 가장자리에 모인다. 작은 로봇·기계는 중앙과 우측에 놓여 있어 건축물의 크기를 읽게 한다. 중앙 바닥은 이동 공간으로 비교적 비워져 있다.
- 전체 색은 채도가 낮은 회색, 갈색, 짙은 녹색이다. 먼 배경은 안개로 대비가 낮고, 노란빛과 청록색이 작은 면적에 집중된다.
- HUD는 좌측의 넓은 자간을 가진 AFTERLIGHT 표식과 장소명, 우상단의 LOCAL SIGNAL 지도, 하단의 FREE CAMERA 조작 패널로 이루어진다. 어두운 청록 반투명 면, 가는 테두리, 미색 텍스트와 금빛 강조가 장면과 연결된다.

## 재구성 기준

Blender에서 편집 가능한 메시로 안뜰·벽돌 담장·건물·상점·배관·상자·로봇을 제작한다. 참조의 높은 사선 카메라, 비워진 중앙, 따뜻한 상점과 청록색 문이라는 시선의 축을 유지한다. 화면 가장자리의 HUD와 문구는 정적 웹 UI로 재해석한다.

텍스처는 독립된 표준 PBR 이미지로 제공하고 메시의 UV에 연결한다. 같은 벽돌·상자 등 모듈의 인스턴스가 UV를 공유하는 것은 의도한 재사용이다. 서로 다른 면을 같은 고유 메시 안에서 겹치는 것과는 구분하며, 내보낸 모델을 다시 가져와 고유 메시 단위로 검증한다.

완성 결과는 한 장의 참조에서 보이지 않는 면을 새로 설계한 재구성이다. 참조 화면의 픽셀이나 보이지 않는 원본 자산을 복원했다고 주장하지 않는다. 실제 결과의 메시 수, 텍스처와 UV 검사, GLB·glTF·FBX 재가져오기 결과는 `export-validation.json`에 기록한다. 렌더와 브라우저 화면은 최종 결과를 기준으로 별도 시각 검증한다.
