# ImageGen texture generation

Built-in image_gen tool. Source generated in this task and copied into assets/surface-atlas.png. Actual output: square four-material atlas; UV mapping deliberately samples the interiors with margins.

Use case: stylized-concept. Asset type: PBR base-color texture atlas for actual UV mapped Blender models, not a scene rendering. Create a square 2048x2048 flat orthographic material sheet split into EXACTLY FOUR equal square quadrants, no gutters, no text, no objects, no perspective, no lighting gradients or cast shadows. Top left: weathered warm gray limestone subtle chipped porous stone surface, no large brick outlines. Top right: dark desaturated green-blue industrial painted metal, chipped edges and small rust freckles, mostly smooth. Bottom left: aged reddish brown rusted iron plate surface with fine scratches. Bottom right: dark weathered brown timber subtle straight vertical grain. Each square is a continuous evenly lit albedo surface, seamless-looking, restrained detailed realistic game texture. For a melancholy rain washed postindustrial courtyard with amber lighting. Keep large forms out; geometry will provide all bricks, planks, panels. No borders, labels, watermarks, specular highlights, baked shadows.
